# Romanian Monetary Dynamics (RMD)

![Version: 0.1](https://img.shields.io/badge/version-0.1-blue?style=flat-square)
![License: MIT](https://img.shields.io/badge/license-MIT-lightgrey?style=flat-square)

Romanian Monetary Dynamics (RMD) is an empirical stock-flow-consistent system-dynamics model of Romania's monetary and macro-financial system. The repository contains the accounting and dynamics engine, empirical and calibration/validation contracts, source and processed data with provenance, and the scripts directly required to obtain or assess those model inputs. It is maintained as a scientific model core rather than an end-user application.
