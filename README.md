<h1 align="center">Romanian Monetary Dynamics (RMD)</h1>

<p align="center">
  <img alt="Version: 0.1.0" src="https://img.shields.io/badge/version-0.1.0-blue?style=flat-square">
  <img alt="License: MIT" src="https://img.shields.io/badge/license-MIT-lightgrey?style=flat-square">
</p>

Romanian Monetary Dynamics (RMD) is an empirical stock-flow-consistent system-dynamics model of Romania's monetary and macro-financial system. The repository contains the accounting and dynamics engine, empirical and calibration/validation contracts, source and processed data with provenance and the scripts directly required to obtain or assess those model inputs. It is maintained as a scientific model core rather than an end-user application.

**Current status:** initial research release / scientific-core baseline, currently in Validation Recovery / Empirical Basis Expansion. No behavioural reference mechanism is yet validated. See [STATUS.md](STATUS.md) for the current scientific scope and [CITATION.cff](CITATION.cff) for citation metadata.
