# Visual identity — InfoClar Model Suite family

Romania Macro-Financial Dynamics belongs visually to the same application family as World3 Empirical and Cognitive Epistemic Model while retaining its own macro-financial symbol and scientific visual language.

## Canonical icon language

The application icon uses:

- a rounded-square tile;
- the shared blue-to-teal gradient `#3689e6` → `#0e9a83`;
- white structural marks for model/system geometry;
- the shared warm-yellow accent `#f9c440` for one focal element;
- simple geometry that remains legible at launcher/favicon sizes.

The macro-financial icon represents reciprocal circulation and balance-sheet links rather than copying the World3 trajectory or the Cognitive Epistemic Model network glyph.

`web/public/icon.svg` is the canonical vector asset. Future web favicons, release artwork and the native elementary OS icon derive from this identity without silently changing the core symbol.

## Application surfaces

InfoClar v1.1 uses restrained neutral surfaces and spacing-led hierarchy. Brand colours identify the product family but do not turn every panel into a branded card. The interface should remain calm, dense enough for scientific work and printable/readable without decorative animation.

Typography, spacing, focus and surface tokens are canonical in `model/registries/design_tokens.json`.

## Scientific visualization

The scientific representation is specific to this model:

- stock-flow and sector relationships;
- From-Whom-to-Whom / Flow-of-Funds matrices;
- empirical macro-financial time series;
- major accounting and later dynamic indicators.

Do not force the project into the diagram grammar of Cognitive Epistemic Model or the trajectory grammar of World3 Empirical.

## Cross-platform rule

The web and future elementary OS/Flatpak application must be recognisable as the same product. Platform adaptation may change control rendering, padding and native conventions, but not semantic names, scientific outputs or core identity.

## Accessibility

Target WCAG 2.2 AA on the web. Do not encode scientific meaning by colour alone. Charts and scientific diagrams use labels, line patterns, symbols and exact-value views where appropriate. Keyboard focus remains visible. The application-icon palette is branding, not a scientific categorical scale.
