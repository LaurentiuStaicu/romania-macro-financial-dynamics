# Visual identity — shared application family

Romania Macro-Financial Dynamics belongs visually to the same application family as World3 Empirical and Cognitive Epistemic Model while retaining its own semantic symbol.

## Canonical icon language

The application icon uses:

- a rounded-square tile;
- the shared blue-to-teal gradient `#3689e6` → `#0e9a83`;
- white structural marks for the model/system geometry;
- the shared warm-yellow accent `#f9c440` for one focal element;
- simple geometry that remains legible at launcher/favicon sizes.

The macro-financial icon represents reciprocal circulation and balance-sheet links rather than copying the World3 trajectory or the Cognitive Epistemic Model network glyph.

`web/public/icon.svg` is the current canonical vector asset. Future web favicons, release artwork and the native elementary OS icon should derive from this identity without silently changing the palette or core symbol.

## Cross-platform rule

The web and future elementary OS/Flatpak application must be recognisable as the same product. Platform adaptation may change padding, export sizes or metadata packaging, but not the core visual identity.

## Accessibility

Do not encode scientific meaning by colour alone. Charts and scientific diagrams must continue to use labels, line patterns, symbols and exact-value views where appropriate. The application icon palette is branding, not a scientific categorical scale.
